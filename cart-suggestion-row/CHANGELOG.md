# Changelog: cart-suggestion-row

## v1.0 (26 Nov 2026)
First release, extracted from the build theme "Build - Cart Upsell".
- Swipeable product row in the cart drawer: collection, heading and product count settings.
- Hides products already in the cart and unavailable products.
- Native variant dropdown (available variants only); price, image, links and Add follow the choice.
- Subscription products show a Choose link to the product page.
- Fixes found while testing: row no longer gets stuck after a cart refresh (`in-viewport`); the dropdown opens inside the draggable row; quick add checkmark keeps its size after the drawer first fills (quick add patch).

Evidence: owner-tested on a phone in the build theme. Fresh install test pending.
